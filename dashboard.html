Global Internet Usage Dashboard

Interactive Streamlit dashboard for exploring worldwide internet usage patterns from 2000 to 2023. The project focuses on data preparation, exploratory analysis, visualization, and communicating global trends through a live dashboard.

The dashboard compares internet usage across continents and countries, highlights countries with high and low internet penetration, and explores relationships between internet usage and GDP per capita.
