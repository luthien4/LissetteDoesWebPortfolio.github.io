Methods & Concepts

The statistical, machine learning, and data engineering ideas
that guide my portfolio projects.

Why This Section Exists

This section is a growing collection of the concepts I use while building data projects. It connects theory with practical decisions: how I choose evaluation metrics, prevent data leakage, handle class imbalance, validate models, engineer features, and interpret results.

The goal is not to document everything I study. The goal is to make visible how I think through data problems and turn technical concepts into clear, defensible analysis.

Modeling Foundations

Notes on regression, classification, cross-validation, train-test splitting, model selection, hyperparameter tuning, and evaluation metrics such as MAE, RMSE, R2, precision, recall, F1-score, and ROC-AUC.

Project Decisions

Short explanations of decisions that appear across my projects: feature availability, data leakage, outlier treatment, class imbalance, preprocessing pipelines, model interpretation, and communicating results to business stakeholders.

Expanding Topics

As new projects are added, this section will grow to include clustering, dimensionality reduction, geospatial analysis, dashboard design, SQL analytics, data engineering concepts, and reproducible project organization.

Current Status

This library will be built gradually as I refine each portfolio project. Each note should support a real project decision, so the section stays practical and connected to applied data work.
